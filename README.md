#Wedding Venue Viewer

<h3>Description</h3>

<p>Wedding Venue Viewer is a web application that allows users to browse wedding venues, view key details, and filter venues based on distance from a specified location.</p>
<a href="https://everetthanke.github.io/WeddingVenuePlanner/">Click here to view page</a>

<h3>Features</h3>

<p>Display a list of wedding venues with relevant details</p>

<p>Filter venues based on maximum distance from a specified location</p>

<p>Interactive table with dynamic filtering</p>

<h3>Technologies Used</h3>
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
